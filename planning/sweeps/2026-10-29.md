## Source and runtime audit

The exact tagged command definitions, help output, implementation, release workflow, and package metadata were audited. The command reference adds the released `pointer` and `manifest` families and their 15 subcommands, corrects address-download output defaults, adds `--download-diagnostics`, states the `ant file cost` wallet behavior, corrects the wallet balance to ANT only, and records the node-add count default.

The installed macOS ARM64 binary reported `ant 0.3.12`. A public mainnet download ran without a wallet:

```bash
ant file download 711c7e20006ff3e0ac6c1f3063286a0c1a3e4c409642e8c526173fa60bb7078a -o lucky.jpg
```

The command completed successfully. `lucky.jpg` contained `138931` bytes and had SHA-256 `98f657d987d339c302295e79907e7a4abc1564bd6b42300ea8d59ccd2148fd17`.

Two non-paying reference examples also ran against the released binary in an isolated temporary directory. `ant pointer keygen` created a new owner key, `ant pointer address` reproduced its address, and `ant manifest create --public-file` wrote a one-entry manifest around the Lucky address that `ant manifest show` read successfully. The generated pointer key is not an EVM payment wallet and was not used on the Autonomi Network.

No wallet was created, funded, or used. A three-byte file cost estimate returned `0.1690 ANT` plus `0.000150 ETH`, but no upload or payment was submitted. Because the paid workflow was not exercised, the onboarding page no longer presents a step-by-step paid upload as verified. Paid commands remain in the reference because their syntax and behavior were audited against the exact released command definitions and source.

## Known security-audit result

The release commit's [CI run](https://github.com/WithAutonomi/ant-client/actions/runs/39874859921) passed formatting, builds, unit tests, browser tests, and Linux/macOS end-to-end suites, but its Security Audit job failed on five public RustSec advisories:

- RUSTSEC-2026-0382 in `rustls-webpki 0.103.15` and RUSTSEC-2026-0383 in `webpki-root-certs 1.0.7` cover certificate paths through distrusted emSign intermediates.
- RUSTSEC-2026-0367, RUSTSEC-2026-0368, and RUSTSEC-2026-0369 cover vulnerable extraction functions in `zip 2.4.2`. The released CLI's extractor does not call those functions.

The ZIP update was already tracked and later merged in [ant-client PR #233](https://github.com/WithAutonomi/ant-client/pull/233). The certificate updates were already tracked and later merged in [ant-client PR #236](https://github.com/WithAutonomi/ant-client/pull/236). Both source fixes landed after `0.3.12` was published, and no newer stable CLI release existed on the audit date. The owner directed this documentation promotion to describe the obtainable stable release rather than block on a known, already tracked source fix. This record does not claim that the `0.3.12` dependency audit passed.
