# Language Bindings

These client libraries run inside your application and send requests to a local daemon, a separately running background service called [antd](../../use-antd.md). Choose your language for installation instructions, examples, and API details.

For libraries that connect directly to the Autonomi Network without a separate service, see [Build with the SDKs](../../install.md). [How Language Bindings Work](overview.md) explains the local-daemon clients in more detail.
